# Holdem Arcade — 포커 룰 미니게임

친구들과 실시간으로 즐기는 포커 룰 변형 미니게임 모음. Node.js + Express + Socket.IO, 빌드 과정 없는 순수 HTML/CSS/JS 클라이언트.

## 게임 1: 기억 포커 (2인)

0. 방을 만들 때 **기억 시간**(5~90초, 기본 30)과 **선택 시간**(5~60초, 기본 20)을 정함. 마지막 설정은 브라우저에 기억됨
1. 두 플레이어 모두 **준비**하면 시작 (시작 칩 1,000)
2. 라운드마다 앤티를 냄 (50 → 50 → 100 → 100 → 150 → 150 → 200 → 200 → 300 → 300)
3. 카드 16장이 **기억 시간** 동안 공개됨 → 둘 다 "다 외웠어요"를 누르면 바로 넘어감
4. 카드가 모두 뒷면으로 뒤집힘 (표시 없음, **위치만 기억**해야 함)
5. 공유 카드 **5장** 공개
6. **선택 시간** 안에 뒤집힌 카드 2장을 위치로 골라 비공개 확정 (상대와 같은 카드 선택 가능). **시간 안에 2장을 고르지 못하면 그 판 실격패**: 다이처럼 쇼다운에서 빠지고 참가비를 잃습니다. 2장을 골라 놓고 확정만 못 누른 경우는 인정(너트 레이스에서는 가장 느린 것으로 처리). 모두 실격이면 그 판은 무효이고 참가비를 돌려줍니다
7. 쇼다운: 내 2장 + 공유 5장 중 베스트 5장으로 승부, 승자가 팟 획득 (동점이면 분배)
8. 10라운드 종료 또는 한쪽 칩 소진 시 게임 종료 → **다시 하기**로 재대결

로비, 방 설정 창, 게임방 상단 `?` 버튼에서 **게임 방법**(단계별 튜토리얼, 족보 순위 포함)을 볼 수 있습니다. 보고 싶은 사람만 열면 됩니다.

## 게임 2: 너트 레이스 (2~6인)

공유 카드 5장과 16장이 **처음부터 모두 앞면**입니다. 제한 시간(기본 20초) 안에 가장 강한 족보가 되는 2장을 골라 확정합니다. **족보가 같으면 먼저 확정한 사람이 승리**하고(2장을 골라 놓고 확정만 못 누르면 가장 느린 것으로 처리, **2장을 다 고르지 못하면 그 판 실격패**), 쇼다운 때 가능한 최강 조합(**NUTS**)을 금색으로 보여줍니다.

## 인원과 봇

- 방을 만들 때 **인원 2~6명**을 정합니다(기본 4명). 정원을 다 채우지 않아도 2명 이상이 모두 준비하면 시작합니다.
- 칩이 0이 된 플레이어는 **탈락**하고 관전하며, 남은 사람끼리 계속합니다. 10라운드가 끝나거나 1명만 남으면 종료.
- 대기실에서 **봇 추가: 하 / 중 / 상**. 봇은 항상 준비 상태이고, 대기실에서 × 버튼으로 내보낼 수 있습니다. 쇼다운 뒤 가끔 이모티콘으로 반응합니다.
- 봇은 서버의 실제 정보를 보되, 난이도에 따라 일부러 실수합니다(`server/bots.js`).

| | 하 | 중 | 상 |
|---|---|---|---|
| 기억 정확도 (카드 1장당) | 45% | 72% | 93% |
| 노리는 조합 | 상위 10개 중 무작위 | 상위 3개 중 | 최강 |
| 고르는 시간 | 6~12초 | 4~9초 | 2.5~6초 |
| 너트 레이스: 넛츠 찾을 확률 / 시간 | 45% / 6.5~13초 | 75% / 3.8~8.5초 | 95% / 2.2~5.2초 |

## 베팅 라운드 (기억 포커 · 너트 레이스)

방 설정에서 켜고 끌 수 있습니다(기본 켜짐). 카드 2장을 고른 뒤, 기억에 대한 자신감으로 한 번 베팅합니다(`memoryPoker.js`의 공용 베팅 엔진). 다이한 사람은 쇼다운에서 빠집니다. 베팅은 남은 사람 중 가장 적은 칩까지로 제한해 사이드 팟이 생기지 않습니다.

## 쇼다운 연출

매 쇼다운마다 승자 스포트라이트가 화면을 덮습니다: 왕관, 승자, 족보 이름, 이긴 5장(승자 본인 카드는 금색 테두리), 팟 카운트업, 컨페티, 아슬아슬한 승부의 이유(속도/키커/모두 다이).

## 프로필 · 랭킹 · 마이페이지

- 가입 없이 브라우저마다 프로필이 자동으로 만들어집니다(무작위 id + 비밀 토큰). 마이페이지의 **계정 이전 코드**를 다른 기기에 붙여넣으면 같은 프로필로 이어집니다.
- **마이페이지**: 프로필 사진(고양이 프리셋 12종 또는 사진 업로드: 브라우저에서 160px로 잘라 압축), 닉네임, 게임별 기록(랭킹 포인트·순위·판수·우승·승률·라운드 승·딴 칩·최고 기록·최근 10경기).
- **랭킹**: 게임별 탭, 상위 50명 + 내 순위. 랭킹 포인트는 1,000점에서 시작하고 게임이 끝날 때 등수에 따라 변합니다(N명 중 k등: `24 × (N − 2k + 1) / (N − 1)`, 예: 2인 ±24, 4인 +24/+8/−8/−24). **봇하고만 한 게임은 절반**, 게임 중 나가면 꼴찌로 기록됩니다.

### 기록 저장소 (중요)

- 기본값은 `data/store.json` 파일입니다. 로컬에서는 그대로 유지되지만, **Render 무료 웹 서비스는 재시작·재배포 때마다 파일이 지워집니다.**
- 기록을 계속 남기려면 Postgres 데이터베이스를 만들고 Render 서비스의 **Environment → `DATABASE_URL`** 에 연결 문자열을 넣으세요. 서버가 자동으로 DB를 사용합니다(`kv` 테이블 하나를 자동 생성).
- 무료 Postgres 예: Neon, Supabase 등(각 서비스 가입 필요). 연결에 실패하면 서버는 파일 저장으로 자동 전환하고 로그에 남깁니다.

## 로비 광장

로비 위쪽은 걸어 다니는 광장입니다. 접속하면 내 캐릭터(프로필 사진 얼굴)가 생기고 **방향키/WASD**로 걷습니다(모바일은 화면을 누르면 그쪽으로 걸어가고, 카메라가 캐릭터를 따라갑니다). 발판 위에 잠깐 서 있으면 게이지가 차고 실행됩니다.

- 빨간 발판: **기억 포커 / 너트 레이스** 방 만들기
- 파란 발판: 랭킹, 마이페이지, 게임 방법
- 아래쪽 초록 **포털**: 열린 방(최대 4개). 들어가면 참가하고, 자리가 없으면 관전합니다(보라색 포털)
- 로비에 있는 다른 사람들도 실시간으로 걸어 다니는 모습이 보입니다(서버가 0.1초마다 위치를 모아 보냄). 아래 게임 카드와 방 목록도 그대로 쓸 수 있습니다.

## 관전 · 중간 참여

- 방이 게임 중이어도 초대 링크·방 목록·포털로 들어올 수 있습니다.
- **자리가 있고 6라운드 전이면 중간 참여**: 시작 칩 1,000으로 앉고, 진행 중인 판은 구경하다가 **다음 라운드부터** 참가합니다(최대 6라운드부터 참가).
- 자리가 없거나 6라운드가 지났으면 **관전**합니다. 관전자는 채팅할 수 있고, 자리가 나면(중간 참여 조건 안에서) **자리 앉기** 버튼이 생깁니다. 게임이 끝난 뒤나 대기실에서도 빈자리에 앉을 수 있습니다.
- 상단 👀 칩에 관전자 수가 표시됩니다. 관전자 최대 20명.

## 공통 기능

- **접속 중 목록**: 로비에 지금 접속한 사람(프로필 사진·닉네임)과 상태(로비 / 대기 중 / 게임 중)가 실시간으로 뜹니다. 대기 중인 방에 있는 사람 옆 **같이 하기**를 누르면 그 방으로 바로 들어갑니다. 같은 프로필로 탭을 여러 개 열어도 한 명으로 표시됩니다.
- **채팅**: 로비(로비 채팅)와 게임방(방 채팅) 모두 오른쪽 아래 버튼이나 **Enter**로 엽니다. Enter로 보내면 다시 게임/광장 조작으로 돌아가고, 로비 메시지는 광장 캐릭터 머리 위 말풍선으로도 뜹니다. 텍스트와 이모티콘을 보낼 수 있고, 보낸 메시지는 그 플레이어 자리 위에 말풍선으로도 뜹니다. 최근 40개는 재접속해도 남아 있고, 도배 방지를 위해 4초에 5개까지만 보낼 수 있습니다.
- **이모티콘**: 직접 그린 오리지널 "모찌 고양이" 16종(SVG, 이미지 파일 없음). `public/stickers.js`에 추가하면 됩니다.
- **한국어 / English**: 오른쪽 위 버튼으로 바꿉니다. 처음에는 브라우저 언어를 따르고 선택은 기억됩니다. 서버는 문장 대신 코드(`srv.full`, `sys.joined` 등)를 보내기 때문에 같은 방에서도 각자 자기 언어로 봅니다. 문구는 `public/i18n.js`에 있습니다.

서버가 카드 정보를 관리합니다. 카드가 뒤집힌 뒤에는 클라이언트로 카드 값을 보내지 않고, 쇼다운 전까지 상대 선택도 숨기기 때문에 개발자도구로 엿볼 수 없습니다.

## 로컬 실행

```bash
npm install
npm start          # http://localhost:3000  (PORT 환경변수로 변경 가능)
npm test           # 족보 판정 테스트
```

같은 PC에서 테스트할 때는 브라우저 탭 2개를 열면 됩니다. 탭마다 별도 플레이어로 인식되고, 새로고침해도 같은 자리로 재접속됩니다.

## Render 배포

1. 이 폴더를 GitHub 저장소로 push
2. Render 대시보드 → **New → Blueprint** → 저장소 선택 (`render.yaml` 자동 인식)
   - 또는 **New → Web Service**: Build `npm install`, Start `npm start`, Health check `/healthz`
3. 배포된 URL을 친구에게 공유 → 방 만들기 → 상단 방 코드를 눌러 초대 링크 복사

참고:
- 무료 플랜은 15분간 접속이 없으면 잠들고, 첫 접속 때 깨어나는 데 30초 정도 걸립니다.
- 방 정보는 서버 메모리에만 있으므로 재배포/재시작 시 진행 중인 방은 사라집니다. 인스턴스는 1개로 유지하세요.

### 새 미니게임 추가하기

`server/games/`에 아래 인터페이스를 가진 클래스를 만들고 `server/index.js`의 `GAMES`에 등록합니다.

- `static meta = { id, name, minPlayers, maxPlayers }`
- `onJoin(player)`, `onLeave(playerId, name)`, `canJoin()`
- `onAction(playerId, action)`: 클라이언트가 `socket.emit('action', {...})`로 보낸 입력 처리
- `viewFor(playerId)`: 해당 플레이어에게 보여도 되는 상태만 반환
- `dispose()`: 타이머 정리

그다음 로비의 `data-game` 카드와 클라이언트 렌더러를 추가하면 됩니다.

## 카드 구분

- **금색 쟁반 + 금테 크림색 카드** = 공유 카드(보드). **파란 쟁반 + 파란 테두리 카드** = 고르는 선택 카드(내 손 카드도 파란 테두리). 각 영역 위에 이름표가 붙습니다.
- 선택 카드 16장과 보드 5장은 한 덱(52장)에서 함께 뽑기 때문에 같은 카드가 두 번 나오지 않습니다(예: 선택 카드에 Q가 4장이면 보드에는 Q가 없음). 단, 여러 플레이어가 같은 선택 카드를 고르는 것은 규칙상 허용됩니다.
